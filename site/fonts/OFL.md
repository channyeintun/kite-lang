# Fonts shipped with this site

## Alfa Slab One

`alfa-slab-one-latin-400.woff2` — the latin subset, regular, 11.5 KB.

- Designed by Josep Patau Bellart.
- Licensed under the **SIL Open Font License, Version 1.1**.
- Source: <https://fonts.google.com/specimen/Alfa+Slab+One>
- Licence text: <https://openfontlicense.org/>

The file is served from this origin rather than linked from a font CDN, so
the site still makes no request to a third party. The OFL permits this:
redistribution of the font, bundled with other software, is allowed provided
the font is not sold on its own and this notice travels with it.

The face is used for the hero title and the band headings. It is *not* the
Kite wordmark — `brand.html` remains the authority for that, and specifies
JetBrains Mono Medium at −2% tracking, which is what the site header uses.
